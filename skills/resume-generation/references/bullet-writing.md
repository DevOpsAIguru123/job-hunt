# Bullet Writing

## Core Rule

Every bullet should show action, scope, and result. Preserve truthfulness.

## Strong Patterns

X-Y-Z:

```text
Accomplished [X] as measured by [Y] by doing [Z].
```

Action plus method plus impact:

```text
Built [system/process] using [tools/method], improving [business or technical result].
```

Scale plus outcome:

```text
Led [scope] across [teams/systems/users], reducing [problem] by [metric].
```

## Rewrite Process

1. Remove weak openings such as `responsible for`, `helped`, `worked on`, and `assisted`.
2. Start with a strong action verb.
3. Add a concrete tool, method, or scope marker.
4. Add a measurable result when available.
5. Keep one main achievement per bullet.
6. Keep bullets concise enough for quick scanning.

## Action Verbs

- Built, Designed, Developed, Launched, Created.
- Automated, Streamlined, Optimized, Modernized.
- Led, Directed, Mentored, Coordinated.
- Reduced, Improved, Increased, Accelerated.
- Analyzed, Diagnosed, Evaluated, Forecasted.
- Resolved, Mitigated, Hardened, Stabilized.

## Quality Check

- The bullet is truthful.
- The user's personal contribution is clear.
- The result matters to the target role.
- The metric is defensible.
- The wording includes supported target keywords naturally.
