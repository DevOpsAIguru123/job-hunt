# Quantification

## Metric Categories

- Money: revenue, cost savings, budget, contract value.
- Time: hours saved, cycle time, response time, delivery time.
- Percentage: growth, reduction, efficiency gain, error reduction.
- Scale: users, customers, records, services, projects, teams, regions.
- Quality: uptime, accuracy, defects, SLA, audit findings.
- Frequency: daily, weekly, monthly, release cadence, report cadence.

## Discovery Questions

Ask only what is needed:

- What changed because of the work?
- What was the before and after state?
- How many users, customers, systems, projects, or tickets were involved?
- How often did this happen?
- How long did it take before and after?
- What quality or reliability measure improved?
- What part of the team effort did the candidate own?

## Estimation

Use estimates only when the user can defend them.

- Prefer ranges when exact numbers are unknown.
- Use lower-bound phrasing such as `100+` or `at least 20`.
- Use relative percentages for confidential business values.
- Add an estimation note when the number is derived.

## Avoid

- Inflated numbers.
- Confidential values.
- Precision that implies false certainty.
- Metrics unrelated to the target role.
- Too many numbers in one bullet.
