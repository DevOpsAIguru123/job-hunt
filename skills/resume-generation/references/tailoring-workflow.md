# Tailoring Workflow

## Target Analysis

For each job, extract:

- Company and role title.
- Required qualifications.
- Preferred qualifications.
- Tools, platforms, languages, and methodologies.
- Domain vocabulary.
- Seniority and leadership signals.
- Repeated verbs and responsibility phrases.

## Resume Strategy

- Use the profile as the source of truth.
- Rewrite the summary around the target role only when supported by experience.
- Put the strongest matching skill groups first.
- Select relevant bullets rather than including all available experience.
- Preserve chronology and dates.
- Keep the resume human-readable; ATS alignment should not make it robotic.

## Output

Each generated resume should include:

- Contact block.
- Professional summary.
- Skills.
- Certifications, if relevant.
- Professional experience.
- Education.

Optional review notes can include:

- Matched keywords.
- Missing but unsupported keywords.
- Why specific bullets were selected.
- Suggested follow-up questions for better tailoring.
